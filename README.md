# VECTORIA QSE

Démonstrateur fictif d’ingénierie qualité, sécurité et environnement au Maroc. Direction visuelle : fiche terrain, repères techniques, contraste minéral et vert signal.

## Fichiers

Quatre pages HTML reliées, une feuille de styles, un script sans dépendance, un logo et un favicon SVG.

## Exécution locale

Ouvrir `index.html` directement ou servir le dossier avec un serveur statique. Le formulaire est volontairement local : aucun envoi réseau n’est effectué.

## Publication

Configuration Netlify incluse pour prévisualisation statique ; aucune publication n’a été réalisée.
